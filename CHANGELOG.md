# Changelog

## 0.1.0-rc.1 — 2026-10-07

- Skill-associated discovery and explicit compact invocation, with local ambiguity refusal.
- Immutable inline/external schema resource views preserving native identities and aliases.
- Validated embedded/external advertisements tied to resolved catalog provenance.
- Explicit metadata binding, independently authored fixtures and installed consumer examples.
- Register externally referenced root anchors without changing acquired schema documents.

Python and framework adapters remain planned; publication remains disabled.

## 0.1.0-rc.0 — 2026-10-06

- Use the unscoped `a2a-schema-contract` package name; package publishing remains disabled.
- Isolate async request, result and staged event validation and resolver compilation in owned workers with deadlines, memory limits, bounded concurrency and explicit shutdown.
- Add sanitized optional diagnostics and operational public imports.
- Retain the inline JSON/text, secure HTTPS resolution, atomic streaming and exact official SDK 1.3.0 profile.
- Add installed-worker, pinned structural, semantic invariant and cold/warm benchmark evidence, release rehearsal, and independent reference security/operation scenarios.

Python, bundles/XML, other transports and full JSON Schema dialect coverage remain excluded. Candidate completion evidence is recorded in the implementation plan and release report.
