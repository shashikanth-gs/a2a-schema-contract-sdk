## SDK-004/005 binding evidence

The combined task report maps acceptance criteria to transport case names,
source boundaries, artifact checks and runtime reports. Raw invalid-input cases
prove zero execution and no TaskStore history write; candidate-output violations,
post-success throws and buffer overflow prove no successful contracted publication.
Independent HTTP peers prove client refusal before codec normalization or result
exposure. Header/context pass-through does not establish a general authorization
system; external resolver/cache security and synchronous work isolation remain
SDK-006/007. The normative source and shared core expectations are unchanged.
